### About this PR

`unstable` had run 483 commits ahead of `main`. Rather than replay those PRs or raise one
enormous merge, the divergence was re-cut into **26 thematic pull requests**, all labelled
`aug2026`, so each can be reviewed, accepted or rejected on its own terms.

The split is a strict partition: all 2,023 changed files are assigned to exactly one PR, with
no file in two of them, and the union reproduces `unstable`'s tree. The five files several
themes genuinely share — four `.cabal` files and `jl4/tests/Main.hs` — were sliced line by line,
so each PR carries only the module registrations its own code needs.

Dependencies between these PRs were **measured, not assumed**: first by resolving every Haskell
import against every sibling's file list and running `npm ci`, and then — once a machine with GHC
was available — by merging candidate sets onto `main` and running `cabal build all`. Import
resolution finds seven edges; building finds that twelve of the PRs are a single indivisible batch,
because the interlocking changes are to *types* in modules `main` already has, which no import-level
check can see. Both are recorded in `.pr-split/DEPENDENCIES.md` and `.pr-split/BATCH.md` on the
branch `claude/unstable-branch-reorganization-6cle91`. Every PR states its own position under
**Independence** above, and each batch member carries the batch roster.
