# L4 documentation

L4 is a programming language for law. You write contracts, legislation and regulations as rules that a computer can check, run and explain.

## Get L4

- **[VS Code extension](https://marketplace.visualstudio.com/items?itemName=Legalese.l4-vscode)**: the editor, the `l4` command, Legalese AI and deployment in one install.
- **[Web editor](https://jl4.legalese.com)**: try L4 in the browser, nothing to install.

## Where to start

- **Learn the language:** take the [Foundation course](courses/foundation/README.md). No programming experience needed.
- **Write a rule now:** [Install L4 and write your first rule](tutorials/getting-started/first-l4-file.md) takes about 15 minutes.
- **Let AI draft it:** [Draft rules with Legalese AI](tutorials/llm-integration/composing-l4-with-ai.md) turns prose into L4.
- **Put rules to work:** [Deploy your rules](tutorials/deploying-rules/exporting-rules-for-deployment.md) as an API that apps and AI agents can call.
