# Case studies — worked L4 analyses

Worked analyses of real legislation and subsidiary instruments, encoded in L4.
These are **not full papers** — they are frank after-action reports and reference
formalisations — but they are valuable writing in their own right, and a natural
source of appendix / worked-example material for the papers in this series (and for
an eventual _Book of L4_).

Imported from `legalese/sandbox` at `mengwong/sample-analyses-2026-07/` (prose +
artifacts travel; any render/build harness stays in the sandbox), the same pattern
used for the Poh Yuan Nie "Letter and the Spirit" essay under
`../formal-methods-in-law/`.

| Study                                       | Dir                      | What it is                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Jersey Covid-19 Gathering Control Order** | `gco-jersey-covid/`      | The _Covid-19 (Gathering Control) (Jersey) Order 2020_ (R&O.166/2020, as amended to repeal) encoded in L4 across three temporal snapshots — first enacted, mid-chain consolidation, and as-repealed — with an after-action report (`GCO-README.md` + `GCO-report.pdf`) written for Matthew Waddington. A rules-as-code / temporal-versioning exemplar. |
| **Jersey Charities Law 2014**               | `charities-jersey-2014/` | Part-by-part L4 formalisation of the Charities (Jersey) Law 2014 (interpretation, the Commissioner, the charity test, the register, governors, appeals, schedules) with a report (`README.md` + `charities-jersey-2014-report.pdf`). A whole-statute encoding exemplar.                                                                                |

Each directory is self-contained (its own README / report + the `.l4` sources).
