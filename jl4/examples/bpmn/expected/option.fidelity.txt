  [F1] blocking — Task_0
      A permission is drawn as a task, so the diagram reads as an instruction to perform it.
      lost: the difference between what a party may do and what it must do; BPMN cannot mark an activity optional
  [P-DEADLINE-UNIT] advisory — Boundary_0
      Deadline ‘30’ carries no unit, because nothing in L4 fixes one — WITHIN is typed as a bare NUMBER (TypeCheck.hs) and the evaluator only ever adds it to an event timestamp. It is read here as days (P30D), following the commonest convention in the corpus, where event clocks are day counts (libraries/daydate.l4, `Day` AKA `Date to days`). A model stamping events in abstract ticks will need this edited.
      lost: certainty about the unit — if this model's clock is not days, the duration needs editing
